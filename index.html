使用方法

01

退出游戏并备份

先完全退出 Trials Survivors，复制整个 SteamID 存档目录。Steam Cloud 可能在游戏运行时覆盖你的修改。

02

载入对应文件

只想改职业就上传职业 STRUCT；想一次查看所有模块就选择整个存档目录，包括 Inventory 子目录。

03

修改并下载

下载文件会保持原文件名。若浏览器自动追加 “(1)”，替换前请恢复成原文件名。

04

替换原文件

把下载后的文件放回原位置。建议主文件和对应 .bak 分开处理，不要同时覆盖唯一备份。

当前版本只对已经从样本中确认过的结构提供快捷编辑。未知遗物/物品对象仍保留在高级 JSON 中，避免生成错误结构。
